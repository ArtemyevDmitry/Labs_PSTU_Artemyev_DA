1. Постановка задачи
Используя оператор цикла, найти сумму целых положительных чётных чисел, меньших 100. Результат вывести на экран, снабдив соответствующим заголовком.
2. Текст программы
#include <iostream> //подключение директив
#include <clocale>

using namespace std; // пространство имен

int main(){ // главная функция
    setlocale(LC_ALL, "Russian"); // подключение кириллицы

    int sum = 0; // инициализация sum
    
    for(int i = 0; i < 100; i++){ //начало цикла
        if (i % 2 == 0){// условие четности чисел
            sum += i;// если верно, то прибавляем текущее к сумме
        }
    }

    cout << "Сумма четных чисел меньших 100 sum = " << sum;// вывод в консоль ответа

    return 0;// код скомпилирован без ошибок
}
3. При запуске программы получаем следующий результат:
Сумма положительных четных чисел, меньших 100: 2450
